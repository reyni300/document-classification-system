# ДокАнализ — Система обработки финансовых документов

Веб-приложение для автоматического распознавания и анализа финансовых документов (чеки, счета, банковские выписки и т.д.) с использованием OCR и LLM.

## Возможности

- Загрузка одного или нескольких документов (PDF, PNG, JPG)
- Предобработка изображений и Tesseract OCR (русский + английский)
- Извлечение структурированных данных через локальную LLM (Ollama Mistral)
- Автоматическая классификация расходов
- Валидация данных
- Интерактивная подсветка полей на документе
- История обработанных документов с фильтрами
- Поиск по проанализированным документам

## Технологии

**Frontend:** HTML + JavaScript (без фреймворков)  
**Backend:** Flask (Python)  
**OCR:** Tesseract  
**LLM:** Ollama (mistral)  
**База данных:** SQLite

## Установка и запуск

```bash
# 1. Клонирование
git clone https://github.com/reyni300/document-classification-system.git
cd document-classification-system

# 2. Установка зависимостей
pip install -r requirements.txt

# 3. Установка внешних инструментов
# Tesseract, Poppler, Ollama + mistral

# 4. Запуск веб-сервера
python web_server.py

Открыть в браузере: http://localhost:5000
